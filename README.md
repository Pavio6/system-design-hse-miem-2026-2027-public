# Системный дизайн: практика. НИУ ВШЭ МИЭМ, 2026/27

## Идея курса

Одна сквозная система, `soldout`: сервис продажи билетов на "дроп" (40 000 мест, 2 000 000 желающих, старт продаж в 12:00). Каждое занятие это один архитектурный шаг: он что-то чинит и что-то ломает, и сломанное становится темой следующего занятия. Система эволюционирует от модульного монолита к распределенной системе с брокером, кластером, сагами и chaos-тестами. Сквозная нить: ИИ-агенты как инструмент архитектора. Формула курса: спецификация → ADR → генерация → fitness functions → проверка.

Курс рассчитан на 16 занятий по 80 минут. Темы идут друг за другом без привязки к датам: если тема не уложилась в занятие, она продолжается на следующем, и это отражено в таблице ниже.

## Как сдавать

1. Форк репозитория, ветка `hwN`.
2. Отчет `hw/hwN/SOLUTION.md` и изменения кода в `soldout/`.
3. PR в свой `main`, ревьюер `nikolaysavelev`, сообщение в Telegram.

В отчете обязателен раздел "Как использовался ИИ" (см. `docs/ai-agents.md`). Использовать агентов разрешено и поощряется; оценивается артефакт и понимание.

## Быстрый старт

Нужны Docker с Compose v2 и `make`. Проверка окружения: `tools/doctor.sh`. Текущее состояние системы (после занятия 5) в ветке `main`; состояния после каждого шага в ветках `demo/*` (см. `lessons/README.md`).

```bash
make up          # стенд текущего занятия: PostgreSQL за PgBouncer, Valkey, Kafka и Debezium, Tempo, Grafana, soldout, notifier
make pay-demo    # один проход покупки: join → hold → order → pay, время каждого вызова
make trace-last  # trace_id последней оплаты и ссылка на трейс в Grafana
make invariants  # инвариант-чекер I1–I6
make lint-all    # go-arch-lint, миграции, semgrep, манифесты
make help        # все цели с описанием
```

Для слабых ноутбуков: `make up-lite` (без Kafka и Connect, доставка событий опросом таблицы outbox). Команды выполняются из корня или из `soldout/`.
